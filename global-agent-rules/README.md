# global-agent-rules

Global collaboration, action boundaries, minimal-change, and verification guidelines in [rules/AGENTS.md](./rules/AGENTS.md).

## Usage

### As a global plugin

Copy or symlink this directory into your global plugins folder so `rules/AGENTS.md` loads across all projects:

```bash
ln -s /path/to/agent-skills/global-agent-rules ~/.gemini/config/plugins/global-agent-rules
```

### Standalone `AGENTS.md`

Copy [rules/AGENTS.md](./rules/AGENTS.md) directly into any project root or global `AGENTS.md` configuration file.
